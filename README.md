# Theodore Simpson — Cybersecurity Portfolio

A responsive, static HTML portfolio featuring **six primary cybersecurity case studies** and **three additional technical labs**, drawn from George Mason University coursework.

## Open locally
Open `index.html` in a browser. Keep the `assets/` directory alongside it.

## Publish on GitHub Pages
1. Create a public GitHub repository for the portfolio.
2. Upload `index.html` and `assets/` preserving paths.
3. In repository Settings → Pages, choose Deploy from a branch, main / root.
4. Add the published URL to your resume.

## Before publishing
Review every screenshot for private data, case identifiers, credentials, and course licensing restrictions. Get permission if required. Do not upload restricted Virginia Cyber Range files or raw evidence. The projects are **academic simulations**, not real client incidents.

## Structure
Featured: network traffic, YARA, vulnerability assessment, Windows logs, VLAN segmentation, password analysis. Additional: email headers, IPv4/IPv6 routing, OSPF.
